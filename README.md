Соревнование: снимки 256×256 px, 20 классов сцен. Выборки: train 4999, val 699, test 8299. Метрика — accuracy.

**Главное в подходе:**
* анализ данных показал, что около 27% снимков val искажены (размытие, сильный JPEG, шум, ч/б, низкий контраст),
  а в train таких около 4%; это компенсируется аугментацией `RandomCorruption`;
* сильные предобученные сети (ResNet-50/101/152 `IMAGENET1K_V2`, Inception v3), дообучаются целиком;
* AdamW, разогрев + косинусное снижение lr, label smoothing, фиксированное число эпох;
* схема holdout → full: оценка на val, затем то же обучение на train + val для предсказаний test;
* TTA: 8 поворотов и отражений, увеличенный тестовый снимок;
* ансамбль: равные веса, правило отбора моделей зафиксировано заранее.

Подробные объяснения — в markdown-ячейках `Kaggle_final/Team_final.ipynb`.

## Что где лежит

| Путь | Что это |
|---|---|
| `Kaggle_final/Team_final.ipynb` | **финальный ноутбук**: все модели (MLP, CNN, предобученные), ансамбль, `final_submission.csv` |
| `Kaggle_team.ipynb` | ранняя версия командного ноутбука (одна модель за запуск); ею обучены r50…inc3_363 |
| `runs/<модель>/` | результаты каждой модели: `summary.json`, варианты TTA на val, история обучения, кривые, вероятности для val и test (`.npy`), сабмит одной модели |
| `runs/submission_ensemble_*.csv` | сабмиты ансамблей, отправленные на Kaggle |
| `tools/ensemble.py` | локальная сборка ансамбля из `runs/` (нужны только numpy, pandas, Pillow) |
| `Moodle/` | **сданный индивидуальный чекпоинт** (не менять) |
| `Week5_checkpoint.ipynb`, `Week5_checkpoint_executed.ipynb` | чекпоинт: чистая версия и прогон с выводами |
| `Week5_baseline.ipynb` | бейзлайн курса |
| `eda/` | скрипты анализа данных (`image_stats.py`, `compare_splits.py`, `tails.py`) и их результаты в `eda/out/` |
| `data/` | данные соревнования: train / val / test и CSV |
| `week5_example/` | маленький пример данных из Moodle |
| `experiments/` | ранний набросок кода экспериментов (не использовался) |
| `tools/kaggle_cpu_benchmark.py` | замер скорости на CPU Kaggle (не понадобился) |

В репозиторий **не входят** файлы больше 100 МБ (их не принимает GitHub):
* архив соревнования — те же данные лежат в `data/`;
* веса моделей `model_full_fp16.pt` — они хранятся на Google Drive аккаунта, где обучалась модель, в папке
  `MyDrive/lab5_runs/<модель>/`.

## Как запускать
1. Colab → *Файл → Загрузить блокнот* → `Kaggle_final/Team_final.ipynb`; *Среда выполнения → T4 GPU*.
2. Архив с данными должен лежать в корне Google Drive (`week-5-competition-geo-satellites-classification.zip`),
   иначе ноутбук скачает его по `DATA_FILE_ID`.
3. В ячейке «1. Настройки» выбрать `RUNS`. Если результаты модели уже есть в `MyDrive/lab5_runs/`
   (`SKIP_DONE = True`), модель не обучается заново.
4. *Выполнить все*. В конце скачается `results_all.zip`: папки моделей, `final_submission.csv`,
   `experiments_team.csv`.

Ансамбль можно пересобрать и локально, без GPU: `python tools/ensemble.py`. Скрипт читает папки моделей из `runs/`.
