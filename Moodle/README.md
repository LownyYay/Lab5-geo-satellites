# Week 5, индивидуальный чекпоинт: классификация аэрокосмических снимков (20 классов)

## Файлы
| файл | содержимое |
|---|---|
| `Week5_checkpoint.ipynb` | ноутбук, выполненный целиком за один прогон в Colab (ячейки по порядку), со всеми выводами, объяснениями и итогами |
| `submission.csv` | предсказания финальной модели для test (8299 строк, `id,label`) |
| `experiments.csv` | таблица экспериментов: модель, настройки, val accuracy, время обучения, seed |

## Результат
* Финальная модель: ResNet-18, предобученный на ImageNet (torchvision), разморожены layer3 и layer4, свой
  классификатор (`Linear 512→256 → LeakyReLU → Dropout 0.3 → Linear 256→20`), соединённый через `nn.Sequential`;
  вход 224×224, нормализация ImageNet, Adam с lr 3e-4, 12 эпох, обучение только на `train.csv`.
* Аугментации: отражения, повороты на 90°, яркость и контраст, а также аугментация с искажениями (размытие,
  низкое разрешение, JPEG, ч/б, шум, низкий контраст), выбранная по итогам анализа датасета (раздел 3 ноутбука):
  около 27% val-снимков искажены, в train — около 4%.
* Val accuracy: **0.934** (± 0.009). Kaggle public leaderboard: **0.92444**.

| модель | val accuracy |
|---|---|
| MLP (32 px) | 0.373 |
| простая CNN (32 px) | 0.544 |
| своя CNN (64 px) | 0.751 |
| ResNet-18, финальная модель | 0.934 |

## Воспроизведение
* Google Colab, GPU T4. Загрузить ноутбук, *Среда выполнения → Выполнить все*. Первая ячейка берёт архив
  соревнования (с Google Drive, если он там есть, иначе по ссылке курса) и распаковывает его в `/content`.
* Seed зафиксирован для Python, NumPy и PyTorch (`SEED = 42`), детерминированный cuDNN, seed для процессов
  DataLoader.
* Время обучения на T4: своя CNN — 2.2 мин, эксперименты с ResNet-18 — от 1.7 до 4.2 мин каждый.
* Версии: Python 3.13.15, torch 2.11.0+cu130, torchvision 0.26.0+cu130, numpy 2.1.3, pandas 2.2.3,
  scikit-learn 1.6.1.
